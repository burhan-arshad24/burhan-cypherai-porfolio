### SMS Spam Classifier

An NLP-based machine learning application that classifies SMS messages as Spam or Ham using TF-IDF and Linear SVM.

The project includes text preprocessing, feature extraction, model optimization with GridSearchCV, and real-time predictions through a Streamlit interface.

**Technologies:** Python, Scikit-learn, TF-IDF, LinearSVC, GridSearchCV, Streamlit

**Performance:** Approximately 99% accuracy and 97% macro F1-score.

* Live Demo: https://nlp-spam-detection-burhan.streamlit.app/
* GitHub: https://github.com/burhan-arshad24/nlp-spam-detection

### Bike Demand Prediction

A machine learning regression project designed to predict bike rental demand using environmental and temporal features.

The project includes datetime feature extraction, exploratory data analysis, model comparison, Random Forest optimization with GridSearchCV, and a Streamlit interface.

**Technologies:** Python, Pandas, Scikit-learn, Random Forest, GridSearchCV, Streamlit

* Live Demo: https://bike-demand-prediction-burhan.streamlit.app/
* GitHub: https://github.com/burhan-arshad24/bike-demand-prediction
